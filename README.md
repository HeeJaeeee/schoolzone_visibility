# 매의 눈

횡단보도 주변의 보행자 시야를 가리는 차량을 감지하고 정차 상황을 알리는 인공지능응용 교과 실습입니다. YOLO26n 기반 사람·차량 탐지에 감시 구역과 정차 시간 조건을 연결했습니다.

## 주요 기능

- 사용자가 사진·영상을 열고 감시 구역, 신호대기 차로, 신호등 영역을 설정합니다.
- 사람·차량 탐지 결과와 감시 구역 안 차량을 표시합니다.
- 정차 기준 시간을 충족하면 알림을 보내고 사진, JSON, CSV 기록을 저장합니다.
- 사진 분석과 영상 감시를 구분합니다. 정차 시간 판단은 영상에서 수행합니다.

## 실행

Python과 Tkinter를 사용할 수 있는 Windows 환경에서 의존성을 설치합니다.

```powershell
python -m pip install -r requirements.txt
python app.py
```

`실행.cmd`의 기존 실행 경로는 원래 개발 환경을 기준으로 합니다. 새 환경에서는 위 명령을 사용하세요. 의존성 목록은 소스의 import를 기준으로 정리했으며, 새 환경에서 전체 설치와 GUI 실행을 재검증한 것은 아닙니다.

`model_choice.json`이 선택한 `weights/detector_v4.pt`와 기존 모델 파일을 포함했습니다. 원본 코드와 모델의 파일 내용은 수정하지 않았습니다. `portable/`에는 패키징 소스와 ONNX 모델을 포함했으며, 배포용 ZIP·EXE와 번들 전체는 포함하지 않았습니다.

## 데이터와 결과

학습·평가 데이터, AI-Hub 원본 영상, 생성 결과와 런타임 캐시는 저장소에 포함하지 않았습니다. 기존 시연 목록은 원래 개발 환경의 외부 자료 경로를 사용하므로, 시연 자료를 별도로 준비하거나 앱에서 직접 사진·영상을 열어야 합니다. 학습·평가 스크립트 전체를 재실행하려면 원본 데이터와 해당 디렉터리 구성이 필요합니다.

실험 과정과 수치, 검수 기록은 저장소의 `학습_평가_결과*.md`, `최종_학습_실행_검수*.md` 등을 참고하세요. 야간·원거리 차량과 장시간 정차 양성 사례가 적다는 한계가 있습니다. 교과 실습 결과이며 현장 적용 성능이나 법적 단속 판정을 입증한 결과는 아닙니다.

## 코드 구성

- `app.py`, `video_window.py`: 사진·영상 화면
- `photo_analysis.py`, `video_analysis.py`, `temporal.py`: 탐지 결과 처리와 정차 판단
- `train*.py`, `evaluate*.py`: 학습·평가 실험
- `test_*.py`: 기존 테스트
- `weights/`, `model_choice.json`: 모델과 선택 정보
- `design/`: 설계 근거
- `portable/`: 배포 패키징 소스

이 저장소는 기존 로컬 프로젝트에서 업로드 대상 소스와 모델을 선별한 복사본입니다. 프로젝트 수행 기간은 별도로 확인해야 합니다.
